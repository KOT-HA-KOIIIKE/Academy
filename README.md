Этот скрипт не проверяет статьи на соответствие редполитике.
Скрипт главным образом предназначен для автоматизации рутинных действий, которые отнимают слишком много времени (проверяет альты и скругления у картинок, находит открывающиеся в том же окне ссылки, собирает список меток, проверяет наличие мета-описания и т.д.).
Скрипт можно оптимизировать и кастомизировать, дело ваше.

Если статья уже опубликована, работаем в файле main.py. В 8 строку вставляем ссылку, кавычки при этом оставляем. Должно получиться так: url = "https://selectel.ru/blog/docker-to-podman/". Далее нажимаем Run, ждем выполнения и идем смотреть результат в файл review.txt.

Если статья еще не опубликована, работаем в файле HTML.py. Сначала открываем из админки Акаедмии предпросмотр -> тыкаем ПКМ -> Сохранить как -> Веб-страница, только HTML. Сохраняем файл, открываем папку с ним, переименовываем файл в латиницу -> тыкаем по файлу ПКМ и выбираем "Копировать как путь". В скрипте вставляем путь в 9 строку. Должно получиться так: file_path = r"C:\Users\user\Downloads\qazxsw.html". Обрати внимание, что путь - это все после r, кавычки вставятся сами. Далее нажимаем Run, ждем, смотрим результат в review.txt.
